# Scene Creator

An app that allow to render and capture a scene using Google Earth.

## Milestone 1

- The app should have top section when we can see the rendered window.
- The app should have a slider that allow to move along the scene.
- The scene path supported are cinematic orbit, fly by, and fly over.
- The app will support next more complex path that will be a collection of paths to go along - think about the data
  structure in advanced

Read the attached directory contain a simple Cesium app that do the same but simpler.
